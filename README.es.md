## 📘 Descripción

Esta aplicación desarrollada con MATLAB App Designer permite analizar el flujo de fluidos en tuberías, mostrando el perfil de velocidades y calculando la pérdida de presión. Es ideal para cursos de mecánica de fluidos, hidráulica y diseño de sistemas de tuberías.

---

## 🧠 Funcionalidades implementadas

- Cálculo de perfil de velocidad en flujo laminar  
- Cálculo de pérdida de presión mediante Darcy–Weisbach  
- Visualización gráfica del perfil de velocidades  
- Configuración de parámetros y condiciones de flujo  
- Interfaz interactiva y fácil de usar

---

## ✨ Características de la aplicación

- Visualización clara del comportamiento del fluido  
- Cálculos rápidos y precisos  
- Gráficos interactivos con opciones de zoom y exportación  
- Orientada a la enseñanza y aprendizaje autodidacta

## 🚀 Cómo instalar

### 🔹 Opción 1: Usar archivo `.mlappinstall`

1. Abre MATLAB  
2. Arrastra el archivo `Velocity and Pressure Profile in Pipes.mlappinstall` a la ventana de comandos  
3. Sigue las instrucciones del instalador  
4. Encuentra la app en la pestaña **Apps**
