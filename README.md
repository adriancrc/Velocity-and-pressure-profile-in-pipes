## 📘 Description

This application, developed with MATLAB App Designer, allows the analysis of fluid flow in pipes by showing the velocity profile and calculating the pressure drop. It is ideal for courses in fluid mechanics, hydraulics, and piping system design.

---

## 🧠 Implemented features

- Calculation of velocity profile for laminar flow  
- Pressure drop calculation using Darcy–Weisbach  
- Graphical visualization of velocity profiles  
- Flow parameters and conditions configuration  
- Interactive and user-friendly interface

---

## ✨ App features

- Clear visualization of fluid behavior in pipes  
- Fast and accurate calculations  
- Interactive graphs with zoom and export options  
- Oriented towards education and self-learning

## 🚀 How to install

### 🔹 Option 1: Using the `.mlappinstall` file

1. Open MATLAB  
2. Drag the `Velocity and Pressure Profile in Pipes.mlappinstall` file into the command window  
3. Follow the installer instructions  
4. Find the app in the **Apps** tab
